# labgemini4 실제 MATLAB 실행 결과

- 실행 코드: `../../matlab/labgemini4.m`
- 실행 환경: MATLAB R2025a
- 조건: 섹터당 43 dBm, NF 7 dB, load_factor 0.5, 26,741개 공통 위치
- `labgemini4_results.mat`: 실제 실행 workspace
- `heatmaps.png`, `capacity_cdf.png`: MATLAB 생성 그림
- `stats.json`: 세 조건의 평균, 중앙값, nearest-rank 5백분위 및 비교 비율
- `matlab_run.log`: 실행 출력
- `summary.csv`: 당시 내보낸 대역폭·평균·중앙값 3열 요약

summary.csv의 Var1은 대역폭 Hz, Var2는 평균 Mbps, Var3은 중앙값 Mbps입니다. 사용자 화면 캡처는 `../earlier_runs`에 별도 보관하며 이 실행 결과와 혼용하지 않습니다.
