## 1 프로젝트 목표와 완료 기준

캠퍼스 위치별 SINR과 단일 스트림 Shannon 전송률을 계산한다. 주파수·대역폭을 비교하고 기존 기지국을 유지하면서 두 곳을 추가한다. 별도 보고서 제출 대신 발표로 결과와 이유를 설명한다.

| 단계 | 조건 | 결과물 |
|---|---|---|
| 1 주파수 비교 | 3.5 GHz/100 MHz, 28 GHz/100 MHz | 공통 색 범위의 SINR 지도 |
| 2 대역폭 비교 | 3.5 GHz/100 MHz, 28 GHz/800 MHz | Capacity CDF, 중앙값, 5백분위 |
| 3 추가 배치 | 기존 유지 + 신규 두 사이트 | 추가 위치 근거, 추가 전후 지도·CDF |

배치 목표는 **28 GHz·800 MHz 전체 5백분위 최대화**로 잡는다. 후보 8곳의 28개 조합을 비교하며, 동률이면 중앙값·평균 순으로 고른다. 3.5 GHz와 실내 성능 변화도 함께 확인한다.

## 4 코드에서 확인한 수정 사항

| 수정 항목 | 확인 내용 |
|---|---|
| 잡음 | −174×1000 대신 대역폭·NF를 반영한 총 잡음전력 |
| 송신 | 전력밀도 −24 대신 총전력 43 dBm/섹터 |
| 주파수 | 경로손실 GHz와 breakpoint Hz 구분 |
| 실내·외부 간섭 | O2I 괄호 수정, 실내 외부 링크에도 같은 손실 적용 |
| 통계 | 중복·가짜 표본 제거, 5백분위와 하위 5% 평균 분리 |
| 지도·안테나 | 실제 dB 색 범위, 섹터 상대각 wrap, LOS/NLOS·shadow fading |

원본 외부 간섭은 이미 선형 전력으로 합산하고 있었다. 따라서 수정 이유를 “dBm을 직접 더하던 코드”로 설명하지 않는다.

원본 수평 패턴 70°/20 dB를 65°/30 dB로 바꾼 것은 표준 수평 소자 패턴을 사용하는 모델 선택이다. 전체 TR 38.901 채널 구현은 아니며 수직 빔포밍·지형·공간 상관·트래픽 스케줄링은 생략한다.

## 5 손계산 검증표

| 검증 항목 | 계산 | 기준값 |
|---|---|---|
| 100 MHz 잡음 | −174 + 10log10(100×10^6) + 7 | −87 dBm |
| 800 MHz 잡음 | −174 + 10log10(800×10^6) + 7 | −77.9691 dBm |
| 잡음 증가 | 10log10(800/100) | +9.0309 dB |
| Shannon 용량 | 100×10^6 × log2(1+1) | 100 Mbps |
| UMa breakpoint | 4×(25−1)×(1.5−1)×3.5×10^9 / 3×10^8 | 560 m |
