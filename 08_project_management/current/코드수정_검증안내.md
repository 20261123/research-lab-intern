# 코드 수정 내역과 검증 기준

## 원본에서 바뀐 계산

| 원본 | 새 코드 | 발표에서 설명할 이유 |
|---|---|---|
| noise_dB=-174*1000 | -174+10log10(B)+NF | 열잡음 전력밀도를 총 잡음전력으로 환산 |
| Pt_dB_Hz=-24 | tx_sector_dbm=43 | 대역폭을 바꾸어도 총전력 고정 |
| fc=4e9를 log 항에 대입 | fc_ghz와 Hz breakpoint 분리 | GHz 항에 Hz를 넣으면 180 dB 오류 |
| NLOS 식만 적용 | UMa LOS/NLOS와 max(LOS,NLOS') | 링크 상태와 breakpoint 반영 |
| O2I 재료 항 괄호 오류 | 두 재료를 로그 안에서 합산 | 혼합 벽의 투과손실 계산 |
| 외부 기지국 Pr만 사용 | 후보·외부에 같은 사용자 O2I 적용 | 실내 간섭도 벽을 통과 |
| 중복 경계와 인덱스 빈칸 | polygon grid 후 unique | 표본 중복과 가짜 0값 방지 |
| Edge_user_C를 반복 덮어씀 | 5백분위와 bottom5_mean 분리 | 서로 다른 통계량 구분 |
| SINR 순위 색상 | 실제 SINR dB와 고정 범위 | 그림 간 정량 비교 |
| 직접 각도 차 | [-180,180)로 wrap | 360° 경계에서 안테나 감쇠 오류 방지 |

원본 SINR 함수는 이미 선형 전력으로 내부·외부 간섭을 합산했습니다. 이 부분을 dBm 직접 합산 오류라고 설명하지 않습니다.

## 검증 함수

`test_campus`는 잡음, Shannon 용량, UMa NLOS 손계산, LOS breakpoint 연속성, O2I, 5백분위, 중복 격자 제거, 외부 간섭, 재현성과 조사 입력 차단을 확인합니다. 외부 기지국까지 같은 O2I를 적용하고 후보를 추가해도 기존 링크 난수가 변하지 않는지도 검증합니다.

| 조건 | 정답/기대 동작 |
|---|---|
| 100 MHz, NF=7 dB | 잡음 -87 dBm |
| 800 MHz, NF=7 dB | 잡음 -77.9691 dBm |
| SINR=1, B=100 MHz | 용량 100 Mbps |
| UMa 3.5 GHz, 25/1.5 m | breakpoint 560 m |
| 같은 서빙 신호에 외부 간섭 추가 | SINR 감소 |
| 같은 seed로 재실행 | 같은 링크 전력 |
| 실제 좌표 양식이 비어 있음 | 세종대 실행 중단 |

## 결과 해석

잡음만 약 9.03 dB 증가했다는 이유로 SINR이 항상 9.03 dB 낮아지는 것은 아닙니다. 간섭이 우세한 위치에서는 영향이 작고, 잡음이 우세한 위치에서는 영향이 큽니다. 주파수를 바꾸면 신호와 간섭이 함께 약해질 수 있으므로 SIR과 SINR을 구분합니다.

기지국 추가로 모든 위치가 개선되리라고 가정하지 않습니다. 기존 서빙 신호와 간섭이 달라지며 일부 지역의 SINR이 낮아질 수 있습니다. 새 배치를 새 seed로 확인한 validation 결과가 최종 근거입니다.

5백분위는 MATLAB quantile의 plotting-position 보간 규칙 `(i-0.5)/n`을 사용합니다. CDF 그림은 경험적 계단 CDF, 통계 표는 보간한 백분위입니다. 큰 표본에서 차이는 작지만 정의를 명시합니다.

## 코드와 모델의 한계

전체 TR 38.901 채널 구현이 아니라 UMa large-scale 교육용 모델입니다. 수직 안테나·빔포밍·공간 상관·실제 건물 차폐·지형·스케줄링을 생략했습니다. 실제 기지국과 완전히 같은 망 성능이라는 주장을 하지 않습니다.
