## 제외한 항목

- `campus_project/.build/matlab_preferences`: MATLAB 개인 설정과 사용 로그.
- `.chart-data-*` 및 `.build/slides`의 candidate/검수 이미지: 최종 발표자료와 중복인 임시 산출물. 발표 생성 스크립트는 보존.
- `report_labgemini4/qa.docx`: 최종 수정본과 동일한 미리보기 복사본.
- `word_render.ps1`, `render_word.vbs`, 비어 있는 변환 폴더: 실패한 페이지 변환 임시 도구.
- `Desktop/matlab저장`의 일반 수업 실습 파일: 통신 프로젝트와 무관한 자료. 연구실인턴 코드 버전 1~4와 campus_project.m은 포함.
