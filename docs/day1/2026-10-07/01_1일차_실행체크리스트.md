## 같은 내용을 이해하기 10~25분

조장이 아래 설명을 읽고 각자 자기 말로 한 번 설명한다.

“캠퍼스 여러 위치에서 가장 강한 기지국 신호를 선택하고, 나머지 신호를 간섭으로 계산한다. 신호·간섭·잡음으로 SINR을 구하고 이론적인 전송률을 계산한다. 먼저 같은 대역폭에서 주파수를 비교하고, 다음에는 28 GHz의 넓은 대역폭을 반영한다. 마지막에는 기존 기지국을 유지하면서 두 곳을 추가한다.”

- [ ] 전원: 신호 S, 간섭 I, 잡음 N의 차이를 설명한다.
- [ ] 전원: `3.5 GHz / 100 MHz`와 `28 GHz / 100 MHz`는 주파수만 바꾸는 비교임을 확인한다.
- [ ] 전원: `3.5 GHz / 100 MHz`와 `28 GHz / 800 MHz`는 주파수·대역폭이 모두 다른 비교임을 확인한다.
- [ ] 전원: 5백분위와 하위 5% 평균은 다른 값임을 확인한다.
- [ ] 조장: 02 결과물 문서의 비교 조건표를 읽고 변경 의견이 있으면 기록한다.

처음 보는 용어는 이렇게 이해한다. **주파수**는 전파가 진동하는 속도, **대역폭**은 통신에 쓰는 주파수 구간의 폭이다. **SINR**은 원하는 신호가 간섭·잡음에 비해 얼마나 강한지 나타낸다. **CDF**는 “이 전송률 이하인 표본이 몇 %인가”를 보여준다. CDF가 0.5인 지점은 중앙값, 0.05인 지점은 5백분위다.

### C 분석 담당이 할 일

- [ ] 아래 계산에서 B가 Hz임을 확인한다.
- [ ] NF=7 dB일 때 잡음이 100 MHz에서 −87 dBm인지 손계산한다.
- [ ] 800 MHz에서 약 −77.97 dBm인지 손계산한다.
- [ ] 두 잡음전력 차이가 약 9.03 dB임을 확인한다.
- [ ] SINR=1, B=100 MHz이면 용량이 100 Mbps인지 확인한다.
- [ ] 02 결과물의 검증표를 검토하고 검토자 이름을 적는다.
- [ ] 예제 CDF에서 y=0.05와 y=0.5에 해당하는 전송률을 읽어본다.

수식: `N_dBm = -174 + 10log10(B_Hz) + NF_dB`, `C_bps = B_Hz × log2(1 + SINR_linear)`.
