# 2026-10-10 연구실인턴 작업 총정리

오늘은 **7개 건물 영역과 캠퍼스 경계 정리 → 경계 내부 취약 구간 분석 → 추가 기지국 두 곳 선정 → 세 조건의 SINR·CDF·5백분위 비교**를 진행했다. 수치는 실제 MATLAB 계산 결과이며, 경계와 설치 가능성은 잠정 가정이다. 원본 labgemini4와 기존 보고서·결과는 보존했다.

## 1. 지도와 평가 영역을 정리했다

- 네이버 지도와 부동산 사이트 경계 이미지를 참고해 7개 모델 영역만 남긴 개념도를 만들었다. 광개토관, 대양홀, 학생회관, 군자관, 집현관, 율곡관·충무관 통합 영역, 학술정보원이다.
- 개념 이미지와 계산용 좌표를 구분했다. 이미지 생성 결과에서 좌표를 추출해 계산하지 않았다.
- 사용자가 승인한 건물 좌표 기반 근사 방법으로 원본 지도 기준점 6개와 코드의 건물 중심을 맞추고 경계 꼭짓점 24개를 추정했다. 기준점 적합 오차는 RMS 16.65 m, 최대 29.21 m이며 남북 끝 일부는 외삽했다. 이 오차는 통계적 신뢰구간이 아니다.
- 계산 격자는 x=-175~175 m, y=-70~615 m, 간격 2.5 m로 확장하고 경계 내부만 평가했다. 평가 위치는 **17,922개: 실내 4,601개, 실외 13,321개**다.
- 원본과 겹치는 기존 26,741개 위치에서 확장 사본의 SINR 차이가 0 dB임을 확인했다. 격자 확장으로 원본 계산식을 바꾸지 않았다.

## 2. 28 GHz·800 MHz 취약 구간 대표점 4곳을 구했다

취약 구간은 신규 기지국 위치가 아니라 **수신 상태가 나쁜 사용자 구간**이다. 선정 규칙은 다음과 같다.

1. 경계 내부 전송률의 하위 10% 기준값 25.37384 Mbps를 사용한다.
2. 대표점 자신이 하위 10%에 속하고, 반경 25 m 안에 경계 내부 표본이 50개 이상 있어야 한다.
3. 주변 표본의 50% 이상이 하위 10%여야 한다.
4. 주변 평균 전송률이 낮은 순서로 선택하고, 이미 선정된 점에서 75 m 미만인 점은 제외한다.

이 규칙으로 후보 중심 1,473개에서 대표점 4곳을 선정했다. 75 m 기준을 50/100 m로 바꾸면 대표점은 5/3곳이므로, 네 곳은 명시한 선정 규칙의 결과다.

| 대표점 | 구간 | 좌표 (x,y), m | 해당 위치 전송률, Mbps |
|---|---|---:|---:|
| W1 | 집현관 | (-75, 77.5) | 1.51 |
| W2 | 군자관 | (-47.5, 147.5) | 6.41 |
| W3 | 광개토관 | (-95, 260) | 8.52 |
| W4 | 대양홀 | (15, 22.5) | 14.04 |

W1은 추정 경계에서 약 2.18 m 떨어져 있어 경계 수정에 특히 민감하다. 현재 계산은 낮은 수신전력, O2I 손실, 잡음·간섭을 분석한 것이다. 다른 건물이 전파를 가렸다는 원인을 건물 차폐 추적으로 검증한 결과는 아니다.

## 3. 후보 수와 평가함수가 다른 세 시나리오를 계산했다

후보 위치는 각 취약점에서 75 m 이내, 추정 경계에서 10 m 이상 안쪽, 모델 건물 외부와 건물에서 5 m 이상, 기존 사이트에서 25 m 이상 이격한다는 기하적 가정으로 생성했다. 신규 사이트 높이는 모두 25 m로 가정했다. 현장 설치 가능성은 아직 확인하지 않았다.

| 시나리오 | 후보 수 / 두 곳 조합 수 | 평가함수 | 동일 비교 표본의 전체 5백분위, Mbps |
|---|---:|---|---:|
| S1 | 4 / 6 | 전체 전송률 5백분위 최대 | 45.77 |
| S2 | 8 / 28 | 사용자별 전송률 비율의 로그 평균 최대 | 44.56 |
| S3 | 12 / 66 | 네 취약 구간 중 가장 낮은 5백분위 개선 비율 최대 | 48.57 |

탐색 8,960개와 비교 8,962개 위치를 격자 교차 방식으로 나눴다. 가까운 위치끼리 나눈 결정론적 비교이므로 독립 난수 검증으로 해석하지 않는다. 후보 집합은 중첩되어 실제 서로 다른 조합 66개를 계산했다.

세 시나리오에서는 S3가 가장 높았다. 하지만 후보 수와 평가함수 효과를 구분하기 위해 **후보 수 3종 × 함수 3종, 총 9조건을 교차 비교**했다. 그 결과 **8개 후보 + 전체 5백분위 최대화**가 비교 표본에서 51.32 Mbps로 더 높았고, 12개 후보에 같은 함수를 적용해도 같은 두 위치가 선택됐다. 따라서 더 적은 후보로 같은 결과를 얻는 8개 후보 구성을 권장했다.

**최종 잠정 추가 좌표: (-127.5, 260) m와 (-17.5, 22.5) m.** 두 위치의 거리는 약 261.74 m다. 검토한 후보와 현재 평가함수에서 선택한 결과이며 연속적인 모든 설치 위치의 전역 최적해는 아니다.

학교 과제는 기존 기지국 유지·두 곳 추가·선정 근거·전후 비교를 요구한다. **8개 후보와 28조합은 학교 지정값이 아니라 프로젝트의 탐색 설계이며, 28은 8개 중 두 개를 고르는 조합 수다.**

## 4. 서비스 11개·외부 간섭 6개로 세 조건을 재계산했다

기존 서비스 9개에 위 두 곳을 추가했다. 외부 간섭 사이트 6개는 유지했다. 서비스/외부 구분은 코드의 역할 구분이며, 정밀 경계 조사로 11개 모두의 실제 교내 위치를 확정한 의미는 아니다.

공통 조건은 섹터당 총 송신전력 43 dBm, NF 7 dB, 간섭 부하율 0.5, 기지국/단말 높이 25/1.5 m, 사이트당 3섹터, 동일 안테나 패턴, low-loss O2I다. 모든 조건에서 같은 추가 위치와 경계 내부 사용자 위치를 사용했다.

| 조건 | SINR 중앙값, dB | 전송률 중앙값, Mbps | 전송률 5백분위, Mbps |
|---|---:|---:|---:|
| 3.5 GHz / 100 MHz | 3.83 | 177.29 | 65.02 |
| 28 GHz / 100 MHz | 2.51 | 147.68 | 32.91 |
| 28 GHz / 800 MHz | -0.02 | 797.61 | 51.40 |

### 1단계: 같은 100 MHz에서 주파수 비교

3.5 GHz에서 28 GHz로 바꾸면 중앙값 전송률은 약 16.7%, 5백분위는 약 49.4% 감소했다. 현재 모델에서는 높은 주파수의 경로손실과 O2I 손실이 영향을 준다. 신호와 간섭이 함께 변하므로 경로손실 증가량을 SINR 감소량으로 그대로 해석하지 않는다.

### 2단계: 3.5 GHz·100 MHz와 28 GHz·800 MHz 비교

28 GHz·800 MHz의 중앙값은 4.50배지만 5백분위는 20.9% 낮다. 넓은 대역폭으로 많은 위치의 전송률이 높아져도 취약 사용자는 여전히 불리할 수 있다. 두 CDF는 교차하며 모든 사용자에게 같은 우열이 나타나지 않는다. 이 비교는 주파수와 대역폭을 함께 바꾼 운용 조건 비교다.

### 28 GHz·100 MHz가 필요한 이유: 대역폭 효과 분리

28 GHz에서 100→800 MHz로 바꾸면 잡음이 -87→-77.97 dBm으로 9.03 dB 증가한다. 중앙값 전송률은 5.40배, 5백분위는 32.91→51.40 Mbps로 56.2% 증가했다. 총 송신전력이 고정되어 SINR이 낮아지므로 대역폭 8배가 전송률 8배를 보장하지 않는다.

### 같은 경계에서 추가 전후 비교

| 조건 | 기존 9개 P5 | 추가 11개 P5 | 개선율 |
|---|---:|---:|---:|
| 3.5 GHz / 100 MHz | 40.83 | 65.02 | +59.3% |
| 28 GHz / 100 MHz | 7.54 | 32.91 | +336.5% |
| 28 GHz / 800 MHz | 8.82 | 51.40 | +482.8% |

단위는 Mbps다. 이전 사각 영역 26,741개 표본의 결과와 직접 비교하지 않는다. 위 전후 값은 모두 같은 잠정 경계의 17,922개 표본이다.

28 GHz·800 MHz 실내 중앙값/P5는 151.87/10.04 Mbps, 실외는 1,068.69/285.89 Mbps다. 전체 평균이나 중앙값만으로 실내 취약성을 설명하면 부족하다.

기지국 추가는 간섭도 증가시켰다. 28 GHz·800 MHz에서 위치의 79.20%는 소폭 감소를 포함한 악화가 있고, 전체 위치의 5.08%는 전송률이 10% 넘게 감소했다. 악화한 위치의 상대 감소율 중앙값은 약 0.68%다. 모든 위치가 개선되었다고 표현하지 않는다.

- 원본 labgemini4의 각도 정규화, 중복 외부 기지국 제거, 실제 SINR 값으로 색상 표시, 부하율 0.5는 기존 수정사항이다. 오늘 새로 수정했다고 중복 기록하지 않는다.
- 오늘은 원본을 보존한 별도 확장 격자와 경계 마스크, 후보 생성·조합 평가, 서비스 11개 세 조건 실행 함수를 추가했다.
- 실행 함수: [배치 조합 평가](../../matlab/evaluate_three_placement_scenarios.m), [세 조건 재계산](../../matlab/run_added_sites_three_cases.m).
- 그림 색상 범위를 세 조건 모두 -30~15 dB로 통일했다. 개별 SINR 3개, 개별 CDF 3개, 비교 SINR/CDF/전후 SINR 3개로 최신 PNG 9개를 저장했다.
- 전체·실내·실외 통계, 위치별 SINR·전송률, CDF 좌표, 기지국 좌표, 악화 분석, 실행 설정, MAT 결과와 검증 기록을 저장했다.

- 체크리스트·역할별 후속 업무·진행 기록과 GitHub 자료 목록을 갱신했다. 초기 코드·보고서와 예제 자료는 별도로 보존했다.

## 6. 발표에서 밝혀야 할 가정과 앞으로 할 일

현재 결과는 **잠정 경계와 labgemini4의 결정론적 모델**에 기반한다. 확률적 LOS/NLOS 선택·shadow fading·독립 난수 20회 검증을 완료한 결과가 아니다. 위치별 단일 스트림 Shannon 전송률이며 실제 다운로드 속도나 셀 전체 동시 처리량이 아니다.

경계 ±30 m와 부하율 0.5/1.0의 6조건에서 권장 배치의 개선을 확인했지만 모든 조건에서 1위는 아니다. 추가 위치 (-127.5,260)은 추정 경계에서 약 12.38 m로 지도 적합 오차보다 가까워 현장 확인이 필요하다. 28 GHz 기준 선정 위치를 3.5 GHz에도 적용했으며 3.5 GHz용 배치를 따로 최적화하지 않았다.
