- 시드·원시 MAT·CSV·6개 그림·paired 구간·QoS 민감도·검증·설명 문서를 보관했다. [독립 20회·장애·대응 결과](../../results/labgemini4/random20_resilience/)

## 2026-10-10 서비스 11개·외부 6개 세 조건 재계산

- 추가 좌표 (-127.5,260), (-17.5,22.5) m를 세 조건에 동일하게 적용하고 MATLAB으로 전체·실내·실외 통계, 히트맵, CDF·5백분위를 생성했다.
- 동일 잠정 경계 17,922개 위치에서 9개 배치도 함께 계산해 경계 변경과 기지국 추가 효과를 분리했다.
- 11개 배치 5백분위는 3.5/100 65.02, 28/100 32.91, 28/800 51.40 Mbps. 중앙값은 177.29, 147.68, 797.61 Mbps.
- 1단계 같은 100 MHz에서 28 GHz 5백분위는 약 49.4% 감소. 2단계 28/800은 3.5/100보다 중앙값 4.50배, 5백분위 약 20.9% 낮음. 실내·실외 차이와 CDF 교차를 설명했다.
- 기존 계산과 수치 일치, 중복·유한 표본, Shannon 수식, 28 GHz 대역폭별 SINR/용량 순서 및 CDF가 1까지 도달함을 확인했다.
- 개별·비교 PNG 9개, 위치별 CSV, CDF 좌표, 악화 분석, MAT 원시 결과와 실행 함수를 저장했다. 자료: results/labgemini4/added11_three_cases/.
- 원본 및 과거 보고서는 보존했다. 정밀 경계·설치 검증·모델 확정·팀 발표 검토는 미완료다.

| labgemini2와 labgemini4 | 상대각·중복·영역·색상·부하율·통계 수정 | 모델 확정·조원 수치 검증·민감도 |

| 2일차 수정 보고서 | 문제점·수정사항·현재 결과 작성 | Word 페이지 배치 확인 |
| 비공개 GitHub 및 Release | 코드·문서·그림·원시 결과 보관 | 최종 발표 버전·제출 |
