# 연구실인턴 진행 기록

## 2026-10-10 후보 수·평가함수 3개 시나리오와 교차 비교

- 취약 구간 4곳에서 구간별 1/2/3개 기하적 후보를 생성해 4/8/12곳의 중첩 집합을 구성했다. 건물 외부·추정 경계·기존 사이트 이격 가정 및 신규 높이 25 m를 기록했다.
- 전체 5백분위, 사용자별 로그 개선 평균, 네 취약 구간의 최소 5백분위 개선 비율이라는 세 평가함수를 MATLAB으로 계산했다.
- 탐색 8,960개 / 비교 8,962개로 격자를 나누고 동일 비교 표본으로 순위화했다. 독립 난수 검증으로 표현하지 않았다.
- 초기 3개 중 S3가 공통 5백분위가 가장 높았지만, 후보 수와 함수 효과를 구분한 9조건 교차 비교에서 8곳+전체 5백분위 함수가 더 높았다. 12곳+같은 함수와 동일 위치여서 적은 후보를 권장했다.
- 권장 좌표 (-127.5,260), (-17.5,22.5) m. 전체 5백분위 8.82→51.40 Mbps, 중앙값 652.11→797.61 Mbps. 사용자 위치 79.20%는 소폭 포함 악화, 10% 초과 감소는 5.08%.
- 6개 경계/부하율 조건에서 개선을 확인했다. 모든 조건의 1위라는 주장은 하지 않았다. 현장 설치·정밀 경계·3.5 GHz 전후·최종 발표는 미완료다.
- 원본 코드와 기존 수치는 보존. 자료: results/labgemini4/three_placement_scenarios/.

## 2026-10-10 잠정 경계 내부 취약점 분석

- 사용자가 건물 좌표로 경계를 근사한 잠정 분석을 선택했다.
- 원본 지도에서 추정한 6개 건물 중심과 코드 중심으로 affine 변환을 맞추고 24개 경계점을 추정했다. 최대 기준점 적합 오차 29.21 m. 남북 끝은 외삽이며 7개 건물 전체 포함을 제약으로 두었다.
- 원본 수식·기지국을 유지한 사본에서 격자 범위만 넓혀 MATLAB 실행. 기존 26,741개 위치와 SINR 차이 0 dB 확인.
- 경계 내부 17,922개 위치의 하위 10% 기준은 25.37384 Mbps. 반경 25 m, 최소 50개 표본, 주변 하위 10% 비율 50% 이상, 평균 전송률 오름차순, 75 m 근접 제거로 대표점 4곳을 선정했다.
- 집현관 (-75,77.5), 군자관 (-47.5,147.5), 광개토관 (-95,260), 대양홀 (15,22.5). W1은 경계까지 2.18 m라 좌표가 민감하다.
- 간격 50/75/100 m와 경계 ±30 m 민감도를 저장했다. 신규 설치 후보나 최적 기지국 2곳 선정 완료로 처리하지 않았다.
- 결과·가정·재현 절차·좌표 CSV·그림: results/labgemini4/weak_regions_provisional/.

## 2026-10-10 체크리스트 갱신

본인의 요청에 따라 지금까지 확인된 작업을 7일 계획에 반영하고 실명 없이 역할별 후속 업무를 배정했다.

| 확인 자료 | 완료 반영 | 남은 작업 |
|---|---|---|
| labgemini2와 labgemini4 | 상대각·중복·영역·색상·부하율·통계 수정 | 모델 확정·조원 수치 검증·민감도 |
| 실행 로그·MAT·stats.json·그림 | 세 조건 실행·전체 통계·Heatmap·CDF | 실내·실외 통계·상세 취약 원인 |
| 2일차 수정 보고서 | 문제점·수정사항·현재 결과 작성 | Word 페이지 배치 확인 |
| 비공개 GitHub 및 Release | 코드·문서·그림·원시 결과 보관 | 최종 발표 버전·제출 |
| 별도 campus_model 예제 | 예제 기능과 실행 기록 보존 | 세종대 후보 8곳·28조합·신규 2곳·추가 전후 |

조원 PC 실행, 팀 전체의 이해, 리허설, 제출은 증거가 없어 완료 처리하지 않았다. 과거 예제 완료를 세종대 완료와 구분했다.

앞으로 파일을 받으면 날짜·파일명·변경 항목·검증 여부·남은 작업을 추가한다. 조건 변경으로 이전 결과가 무효가 되면 체크리스트를 재검토 상태로 바꾼다.
