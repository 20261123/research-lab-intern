# 연구실인턴 진행 기록

## 2026-10-10 체크리스트 갱신

본인의 요청에 따라 지금까지 확인된 작업을 7일 계획에 반영하고 실명 없이 역할별 후속 업무를 배정했다.

| 확인 자료 | 완료 반영 | 남은 작업 |
|---|---|---|
| labgemini2와 labgemini4 | 상대각·중복·영역·색상·부하율·통계 수정 | 모델 확정·조원 수치 검증·민감도 |
| 실행 로그·MAT·stats.json·그림 | 세 조건 실행·전체 통계·Heatmap·CDF | 실내·실외 통계·상세 취약 원인 |
| 2일차 수정 보고서 | 문제점·수정사항·현재 결과 작성 | Word 페이지 배치 확인 |
| 비공개 GitHub 및 Release | 코드·문서·그림·원시 결과 보관 | 최종 발표 버전·제출 |
| 별도 campus_model 예제 | 예제 기능과 실행 기록 보존 | 세종대 후보 8곳·28조합·신규 2곳·추가 전후 |

조원 PC 실행, 팀 전체의 이해, 리허설, 제출은 증거가 없어 완료 처리하지 않았다. 과거 예제 완료를 세종대 완료와 구분했다.

앞으로 파일을 받으면 날짜·파일명·변경 항목·검증 여부·남은 작업을 추가한다. 조건 변경으로 이전 결과가 무효가 되면 체크리스트를 재검토 상태로 바꾼다.

## 2026-10-10 조원별 업무 PDF 작성

- 역할별 할 일, 결과물, 팀 결정 사항, 작업 인계 순서를 2쪽 PDF로 작성했다.
- 두 페이지를 이미지로 렌더링해 한글·체크박스·줄바꿈·잘림을 확인했다.
- README와 역할별 업무 문서에서 공유용 PDF로 연결했다.
- 자료 작성 완료만 체크했으며 조원들의 실제 실행·분석·배치 선정·발표 완료 상태는 바꾸지 않았다.

## 2026-10-10 세 조건 SINR 히트맵 재생성

- labgemini4 원본을 다시 실행하고 3.5 GHz/100 MHz, 28 GHz/100 MHz, 28 GHz/800 MHz의 개별 PNG와 3조건 비교 PNG를 생성했다.
- 사이트·격자·모델·부하율 0.5는 그대로 두고 그림을 내보내는 함수만 별도로 추가했다.
- 공통 색상 범위 -15~25 dB, 건물 외곽선, 서비스/외부 사이트 표시를 확인했다.
- 26,741개 위치의 좌표 중복 없음, 모든 SINR의 유한값, 같은 위치에서 28 GHz/800 MHz SINR이 100 MHz를 넘지 않는지 검증했다.
- 전송률 통계는 기존 실행값과 일치했다. 조원 PC 검증과 세종대 추가 배치 작업은 아직 별도 미완료다.
